# 多 Tab 教程审片台设计

日期：2026-06-15

## 背景

当前审片台最早围绕「AI优化商品图」保姆教程搭建，已经支持底图替换、红框、鼠标、字幕、放大图、插入镜头、删除镜头、拖动排序和一键生成横版视频。

随着教程类型增加，继续把所有内容塞进单个审片台会有两个问题：

- 一个页面只能服务一个功能，新增 `AI批量生成视频` 时容易和旧 `AI优化商品图` 互相污染。
- 单功能保姆教程、单功能效果对比、玩法串联视频本质不同，不能共用同一个开头、同一套分镜结构和同一个输出目录。

用户希望审片台升级为多大 tab：每个功能点击进去后，进入该子功能的详细分镜脚本。第一版先覆盖三块：

- `AI图片 / AI优化商品图`
- `AI视频 / AI批量生成视频`
- `玩法组合 / AI优化商品图 -> 确认发布 -> AI批量生成视频`

## 决策

采用「教程 Hub + 独立教程工程」方案。

顶层审片台只负责导航、选择教程和触发当前教程出片；每个子功能仍然保留自己的分镜、素材、审片状态和输出目录。

不把所有教程合成一个巨大的 HTML，也不把 `AI批量生成视频` 强塞进旧的 `2026-05-29-horizontal-v7` 工作区。

## 信息架构

### 1. 顶层大 tab

第一版大 tab：

- `AI图片`
- `AI视频`
- `玩法组合`

每个大 tab 下方展示子功能卡片。子功能卡片至少包含：

- 教程名称
- 教程类型
- 当前状态
- 输出目录
- 最近生成视频路径
- 进入审片
- 一键生成
- 打开视频
- 打开文件夹

### 2. 子功能

第一版子功能：

| tab | 子功能 | 教程类型 | 目标 |
| --- | --- | --- | --- |
| AI图片 | AI优化商品图 | `operation-tutorial` | 教客户从入口到确认发布怎么一步步操作 |
| AI视频 | AI批量生成视频 | `operation-tutorial` | 教客户选择平台、店铺、商品并生成视频 |
| 玩法组合 | AI优化商品图到AI批量生成视频 | `playbook-chain` | 展示从老商品图优化、确认发布到批量生成视频的一条龙玩法 |

后续新增 `AI去除水印`、`AI换脸&打码`、`AI改尺寸` 时，只新增子功能配置和对应工程，不改旧教程数据。

## 教程类型边界

### operation-tutorial

纯保姆教程。重点是客户知道怎么操作：

- 鼠标点哪里
- 下拉怎么打开
- 店铺怎么选
- 勾选框怎么勾
- 确认、跳过、发布、生成在哪里
- 生成后在哪里看结果

视频开头直接进入后台，不做复杂包装。

### single-feature-compare

单功能快对比。第一版 Hub 只预留类型，不强行上线。

适用场景：

- 主图加卖点
- 品牌展示可自定义
- SKU图规格更清楚

它可以用前后对比、点击率提升、转化率提升、效果图矩阵，但不替代保姆教程。

### playbook-chain

玩法串联。重点是业务链路，不是逐按钮教学：

```text
商家问题
-> AI优化商品图
-> 确认发布
-> AI批量生成视频
-> 可投放素材结果
```

它不使用单功能快对比的开头，也不跳过确认发布和生成记录。

## 页面设计

### 顶层 Hub

Hub 首页结构：

- 顶部标题：`客户教程视频审片台`
- 顶层大 tab：`AI图片 / AI视频 / 玩法组合`
- 左侧或卡片区：当前 tab 下的子功能列表
- 右侧：当前子功能概览、最近视频、快捷操作

快捷操作：

- `进入审片`
- `一键生成当前教程`
- `打开视频`
- `访达定位`
- `打开视频文件夹`

### 子功能审片页

进入子功能后，继续使用现有审片体验：

- 批改状态默认 `通过`
- 支持 `需修改 / 重拍 / 删除 / 待确认`
- 支持底图从素材库选择
- 支持红框和鼠标手动添加、拖动、缩放
- 支持字幕位置拖动
- 支持放大图新增、替换、删除、完整显示和局部展示
- 支持在此前/此后插入镜头
- 支持拖动镜头排序
- 支持一键生成当前教程

区别是：所有状态必须按 `tutorialId` 隔离，不能让 A 教程的删除镜头、红框或字幕覆盖到 B 教程。

## 路由建议

第一版可以只做本地 Node 服务，不上复杂前端框架。

建议路由：

```text
GET  /                         Hub 首页
GET  /tutorial/:tutorialId      某个教程审片页
POST /api/tutorial/:id/build    生成当前教程视频
POST /api/tutorial/:id/open     打开当前教程视频
POST /api/tutorial/:id/reveal   Finder 定位当前教程视频
GET  /api/tutorials             返回教程目录
```

如果第一版为了少改动，也可以让 Hub 的 `进入审片` 先跳转到现有端口：

- `AI优化商品图` -> `http://127.0.0.1:3829/`
- `玩法组合` -> `http://127.0.0.1:3839/`

但长期目标是统一入口，避免用户记多个地址。

## 状态隔离

每个教程必须独立保存：

- `storyboard/review-overrides.json`
- `storyboard/browser-layout.json`
- `manifests/*.json`
- `frames/`
- `audio/`
- `videos/`
- `reports/`

删除镜头必须只影响当前教程。点击 Hub 顶部一键生成时，也只读取当前 `tutorialId` 对应的输出目录和审片状态。

## 旧功能迁移

第一版不迁移旧数据。

`AI优化商品图` 只在 Hub 里登记入口，继续使用：

```text
/Users/gd/Desktop/主业/客户教程视频/稿定商品-AI优化商品图/2026-05-29-horizontal-v7
```

这样可以避免为了做 Hub 破坏已经调过很多轮的保姆教程。

## AI批量生成视频第一版内容

`AI批量生成视频` 的保姆教程需要单独采集和审片，不从玩法视频里截假画面。

第一版镜头建议：

1. 进入 `AI视频 > AI批量生成视频`
2. 选择平台
3. 打开店铺下拉并选择 `道理门`
4. 看设置区：原商品有视频时跳过或覆盖
5. 展开筛选项
6. 选择/确认商品列表
7. 点击 `立即生成`
8. 查看生成记录
9. 说明生成后哪里预览、哪里确认、哪里发布或处理

如果实际路径或控件不确定，必须先实测采集，不用凭空截图补。

## 玩法组合入口

玩法组合 tab 里先挂已有：

```text
AI优化商品图 -> 确认发布 -> AI批量生成视频
```

它使用 `playbook-chain`，不是保姆教程。入口文案应提醒：

- 这是玩法视频，不是逐按钮新手教程。
- 素材来自真实后台截图、AI效果图和生成结果。
- 适合给客户讲“这套功能组合能解决什么经营问题”。

## 非目标

- 不在第一版做权限、账号体系或多人协同。
- 不在第一版做云端部署。
- 不在第一版重写所有旧审片台代码。
- 不在第一版强行统一所有历史输出目录。
- 不做短视频干货风。
- 不做竖屏版。
- 不自动充值。
- 不在非测试店发布。

## 验收标准

- Hub 首页能看到 `AI图片 / AI视频 / 玩法组合` 三个大 tab。
- `AI图片` 下能进入 `AI优化商品图` 审片台。
- `AI视频` 下能进入 `AI批量生成视频` 教程工作区。
- `玩法组合` 下能进入 `AI优化商品图 -> 确认发布 -> AI批量生成视频` 工作区。
- 每个子功能的一键生成只生成当前教程，不会混入其他教程镜头。
- `删除` 状态的镜头不会进入当前教程成片。
- `SKU` 配音读作 `S K U`，`AI` 配音读作 `A I`。
- 生成成功后能直接看到 `打开视频 / 访达定位 / 打开视频文件夹`。
- 旧 `AI优化商品图` 正式视频路径不变：

```text
/Users/gd/Desktop/主业/客户教程视频/稿定商品-AI优化商品图/2026-05-29-horizontal-v7/videos/nanny-horizontal-storyboard.mp4
```

## 风险和处理

- 风险：Hub 做太大，拖慢当前视频交付。
  - 处理：第一版只做目录、入口和当前教程生成；高级素材库和统一播放器后置。
- 风险：旧审片台状态被新 Hub 覆盖。
  - 处理：第一版不迁移旧输出目录，只登记入口；写状态时必须带 `tutorialId`。
- 风险：AI批量生成视频路径不熟，容易编造镜头。
  - 处理：先实测采集；路径不确定就标记待采集，不出假闭环。
- 风险：玩法组合和保姆教程混淆。
  - 处理：教程配置里强制 `templateType`，不同类型使用不同文案和出片入口。

## 后续扩展

- 增加素材库全局筛选：操作截图、生成结果、主图、SKU、品牌展示、AI视频结果。
- 增加单功能快对比模板。
- 增加每个教程的封面、时长、最后生成时间和版本号。
- 增加批量导出多个教程视频。
- 增加同内网多人审片入口，但不做公网开放。

## 实现顺序建议

1. 新增 `configs/tutorials.json`，先登记三条教程。
2. 新增 Hub 服务或扩展现有 server，提供 `/` 和 `/api/tutorials`。
3. Hub 能跳转到现有 `AI优化商品图` 和 `玩法组合` 审片台。
4. 新建 `AI批量生成视频` 输出目录和空教程工作区。
5. 为 `AI批量生成视频` 做真实截图采集和保姆分镜。
6. 给 Hub 的每个教程卡接入一键生成、打开视频和 Finder 定位。
7. 验证旧 `AI优化商品图` 不受影响。
